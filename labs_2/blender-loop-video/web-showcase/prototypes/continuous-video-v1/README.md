# 连续视频滚动 UI 原型 v1

这是独立原型，不修改 `web-showcase` 正式页面。视频固定铺满视口，页面滚动映射到 10 秒成片时间轴；五个叙事状态只改变文字、索引和细线界面，因此场景之间不存在独立页面间隔。

原型验证重点：

- 视频和维纳斯始终是同一个视觉主体。
- 全景、面部、修复结构、衣袍和循环闭合由真实视频时间轴提供。
- 标题放在视频左侧安全区，维纳斯保留在右侧并允许局部出框。
- 铜色接缝线、章节进度、文字遮罩和视频 scrub 构成主要动效。

在 `web-showcase` 目录运行 `python -m http.server 5174` 后打开：

`http://127.0.0.1:5174/prototypes/continuous-video-v1/`

详细设计见 [prototype-plan.md](prototype-plan.md)，原型状态截图位于 `previews/`。
