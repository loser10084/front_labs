# 连续视频滚动 UI 原型 v2 · 1080p

这是独立原型，不修改 `web-showcase` 正式页面。素材来自最终 1920×1080、30 FPS、10 秒成片，但滚动显示已改为300张WebP帧组成的Canvas序列，绕开浏览器MP4随机seek延迟。Canvas固定铺满视口，页面滚动映射到成片帧序列；五个叙事状态只改变文字、索引和细线界面，因此场景之间不存在独立页面间隔。

原型验证重点：

- 视频和维纳斯始终是同一个视觉主体。
- 全景、面部、修复结构、衣袍和循环闭合由真实视频时间轴提供。
- 标题放在视频左侧安全区，维纳斯保留在右侧并允许局部出框。
- 铜色接缝线、章节进度、文字遮罩和Canvas帧scrub构成主要动效。
- 300张压缩帧启动时预载到内存；只保留当前附近约42张已解码位图，避免一次解码全部帧。
- 帧编号与滚动距离保持线性映射；每个绘制周期直接采样最新目标帧，不建立逐帧追赶队列，用户停止滚动后不会继续补播积压帧。
- 页面禁用 CSS 平滑滚动，锚点导航与脚本定位不再额外产生滚动惯性。
- 默认启用“直控”滚轮模式：阻止浏览器直接消费纵向 wheel 事件，根据连续增量是否呈衰减趋势过滤设备惯性尾段，只将确认过的输入同步到页面滚动、文字状态和Canvas帧。右侧滚动条拖拽、键盘滚动和锚点跳转仍采用浏览器原生行为。
- 页眉“滚动”按钮可在“直控”和“原生”之间即时切换，便于用同一套素材做 A/B 对照。使用 `?scroll=native` 可直接以原生模式打开。
- `window.__scrollCanvas` 会记录当前模式、接受/丢弃的wheel事件数量、最近输入增量、目标帧和显示帧，便于在真实触控板上检查惯性尾段是否被过滤。

在 `web-showcase` 目录运行 `python -m http.server 5174` 后打开：

`http://127.0.0.1:5174/prototypes/continuous-video-v2-1080p/`

详细设计见 [prototype-plan.md](prototype-plan.md)，原型状态截图位于 `previews/`。
