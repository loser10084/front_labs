# 10 秒无缝循环背景视频制作方案

## 1. 实验目标

使用 Codex + Blender 制作一个可直接作为网页视频素材的 10 秒无缝循环视频，并验证 Codex 能否把用户的视觉预期转换为可验收的 Blender 成片。

本实验不以“文件成功导出”为成功，而以“视频循环正确且视觉达到高级炫技效果”为成功。第一版使用程序化流动雕塑、丰富的场景层次、精细材质和可精确循环的关键帧，避免角色绑定、布料、流体和不可控粒子模拟。

### 成功条件

- 视频长度为 10.000 秒，允许误差不超过 1 帧。
- 1920 × 1080，16:9，30 fps，共 300 个成片帧。
- 第 300 帧播放后回到第 1 帧时，没有可感知的跳变、停顿或曝光变化。
- 画面可以被网页 `object-fit: cover` 裁切，在桌面和移动端仍保留主体与负空间。
- 画面没有文字、Logo 和依赖声音才能理解的内容。
- H.264 MP4 无音轨，目标文件不超过 15 MB；必要时补充 WebM。
- 流动雕塑、空间结构、材质和光影具有明确层次，不能只呈现基础几何体、默认材质或单灯光效果。
- 通过技术验收后，还必须通过用户对灰模、LookDev 静帧和 10 秒预览的三次视觉验收。

## 2. 修订后的视觉方案

暂定名称：**Restored Venus / 修复中的女神**。

画面采用缓慢闭合运动的相机，一件未来考古修复语境中的断臂古典女神像从大型展厅的暗部显现。雕像穿一体雕刻的贴体高领石质内袍，服装属于雕像几何，不作为飘动布料。主体约 40% 暖象牙色大理石、30% 黑曜石修补、20% 烟熏透明树脂填充、10% 深色旧金属接缝；破损控制在约 15%–20%，脸、头发、颈部和主轮廓保持完整。

雕像从低矮黑色基座或地面裂口中生长出来，背景为有尺度依据的大型展厅或仪式性空间。构图保留右侧主体，但让雕像抵近镜头并局部出框，占画面高度约 70%–85%；左侧保留低细节网页文字区。材质比例修订为约 40% 暖象牙色大理石、30% 黑曜石、20% 烟熏透明树脂、10% 深色旧金属连接结构；替换材质使用大块连续分区，不做细碎拼贴。动态元素只允许来自雕像本身的 3–5 块有明确对应关系的碎片、少量尘埃和扫描光，不再使用无意义棍状物。

灯光采用博物馆级冷暖双主光、克制轮廓光、动态遮光图案和受控体积光。循环运动来自闭合相机轨迹、缓慢扫描光、尘埃和少量对应碎片的微幅闭合运动；雕像本体保持庄重稳定，不做廉价平移、整体自转或软体扭曲。

选择这个方案的原因：

- 具象古典主体让“高级感”有明确审美锚点，不再依赖抽象几何堆料。
- 多材质修复、破损边缘和展厅尺度可以同时验证材质分层、灯光、景深与编码链路。
- 主体保持稳定、环境与镜头闭合运动，既符合博物馆装置语义，也更容易保证无缝循环。
- 混元负责主体几何，Blender 负责修复材质、展厅、构图、灯光和循环动画，职责边界更清晰。

### 构图约束

- 女神像位于画面右侧并抵近镜头，占画面高度约 70%–85%，允许右侧和下沿被有意识裁切，但脸部与断臂轮廓必须始终可识别。
- 左侧约 35%–40% 保持相对低细节，作为网页文字安全区；低细节不等于纯空白，允许低对比建筑层次和缓慢光影。
- 画面至少包含前景遮挡、中景主体、后景空间三个景深层级。
- 不让最亮高光长期占据四角，避免网页固定 UI 失去对比度。
- 移动端中心裁切后仍能看到脸部、断臂轮廓与至少两种修复材质。

## 4. 无缝循环的核心方法

### 4.1 时间定义

令循环周期 `P = 300` 帧。所有动画属性都必须满足：

```text
state(frame 1) == state(frame 301)
```

成片只渲染第 1–300 帧。第 301 帧只用于验证；如果把第 301 帧也编码进去，首帧会被重复一次，循环处反而可能出现轻微停顿。

### 4.2 可接受的动画方式

- 雕塑形变：用周期相位驱动扭转、厚度、波形和发光脉络，所有频率使用整数周期。
- 沿闭合曲线运动：使用周期参数或 Cycles F-Curve Modifier。
- 材质脉冲：使用以 300 帧为周期的正弦函数。
- 悬浮碎片：使用固定实例、闭合轨迹和循环相位，不使用随机出生、死亡系统。
- 灯光：允许通过整数周期旋转遮光图案或改变强度，首尾状态必须一致。
- 相机：沿小幅闭合轨迹运动，并保持首尾位置、旋转、焦距和景深一致。

### 4.3 禁止项

- 不使用无法可靠重置状态的刚体、流体、布料和烟雾模拟。
- 不使用非周期噪声直接驱动物体位置或材质参数。
- 不通过首尾交叉淡化掩盖错误循环。
- 不在未验证首尾状态前启动高分辨率最终渲染。

## 5. Codex + Blender 分工

### Codex 负责

- 读取 Blender 版本、插件状态和当前场景，不假设默认环境。
- 生成可重复执行的 `bpy` 脚本，并按场景、材质、动画、渲染拆分步骤。
- 使用稳定的对象、集合和材质命名，避免依赖本地化界面名称。
- 设置关键帧、循环约束、相机、灯光、渲染参数和输出路径。
- 每一步调用视口截图和场景信息进行确认。
- 执行低分辨率预览、首尾帧验证和最终渲染。
- 使用 Blender 自带 FFmpeg 将无损帧序列编码成网页视频。

### Blender 负责

- 场景、材质、Geometry Nodes 和关键帧的实际计算。
- Eevee/Cycles 渲染。
- PNG 帧序列输出。
- 通过内置 FFmpeg 编码 MP4；如之后提供独立 FFmpeg，再增加命令行复核。

### 用户负责的验收点

- Gate 1：灰模构图。
- Gate 2：高级材质、灯光、空间层次和色彩。
- Gate 3：720p、10 秒完整循环预览。
- Gate 4：最终 1080p 成片。

Codex 负责技术指标检查，用户拥有 Gate 1–3 的视觉否决权。每个 Gate 只确认一个层级，避免在最终渲染后才修改构图或运动。

## 6. 分阶段制作流程

### Gate 0：环境连通

1. 启动 Blender 和 `mcp-for-blender` 本地服务。
2. Codex 调用 `get_addon_status`，记录 Blender 版本和插件状态。
3. Codex 调用 `get_scene_info`，确认当前场景内容。
4. 新建本实验专用 `.blend` 文件，不覆盖用户已有场景。
5. 输出空场景视口截图作为初始证据。

通过条件：Codex 可以读取场景、执行一个无副作用测试并取得视口截图。

### Gate 1：灰模与构图

1. 创建流动雕塑主体、前景框架、后景建筑层、反射地面和闭合相机轨迹。
2. 使用纯灰材质和基础三点布光，不做正式材质。
3. 输出第 1、76、151、226 帧四张分镜图。
4. 分别检查桌面 16:9 和移动端中心裁切。

通过条件：主体轮廓清楚，前中后景成立，文字安全区成立，四个相位都具有展示价值且没有碰撞和突兀裁切；用户明确确认构图方向。

### Gate 2：循环动画

1. 用统一的 300 帧相位驱动雕塑的扭转、呼吸和波形形变。
2. 为相机、悬浮碎片和灯光遮片建立闭合轨迹，所有运动使用整数周期。
3. 添加固定实例碎片、发光脉络和周期性材质变化。
4. 单独渲染第 1 帧和第 301 帧进行差异比较。

通过条件：第 1 帧和第 301 帧的几何、相机、灯光和材质状态一致；预览循环不存在速度突变。

### Gate 3：材质和 720p 预览

1. 添加深色钛金属、烟熏玻璃、虹彩薄膜和受控自发光。
2. 建立冷暖双主光、轮廓光、动态遮光图案、反射地面、低密度体积光、景深和运动模糊。
3. 先输出第 1、76、151、226、301 帧组成镜头分镜，确认景别、观察角、文字安全区及循环首尾；避免五帧只是同一构图的轻微漂移。
4. 分镜通过后再渲染完整 300 帧，并编码 10 秒 720p MP4，连续播放至少 5 次。

通过条件：完整预览在 5–10 分钟内完成；循环接缝不可感知，曝光稳定，材质与光影不显朴素，画面足以用于视觉展示，同时保留网页正文安全区；用户明确批准完整预览。

镜头叙事应围绕主体细节组织（例如展厅建立、主体/面部接近、材质细节揭示、回到建立镜头），而非仅增加几厘米的相机漂移。循环端点不仅要位置与焦距一致，也应检查首尾切线，避免在接缝处骤停或反向。

### Gate 4：最终渲染

1. 锁定场景，不再修改构图和运动。
2. 以 1920 × 1080 渲染 PNG 帧序列到 `renders/frames/`。
3. 渲染中断时从缺失帧继续，不直接输出视频文件。
4. 使用 Blender 自带 FFmpeg 编码到 `output/`。
5. 输出 poster，并保留第 1、76、151、226、301 帧作为验收证据。

通过条件：Eevee 优先，完整渲染耗时控制在 30–90 分钟；技术规格、视觉循环和网页裁切全部通过。

## 7. 脚本拆分建议

正式制作时在 `scripts/` 中形成以下可重复执行的脚本：

```text
00_scene_reset.py        # 仅清理本实验命名空间，不误删用户对象
01_scene_setup.py        # 分辨率、帧率、世界、集合和输出路径
02_geometry.py           # 流动雕塑、空间框架、地面和悬浮碎片
03_materials.py          # 材质和节点
04_animation.py          # 周期动画和首尾约束
05_camera_lighting.py    # 相机、灯光和安全区
06_render_preview.py     # 四帧分镜和 720p 预览
07_render_final.py       # 最终 PNG 序列
08_encode_video.py       # Blender 内置 FFmpeg 编码
09_validate_loop.py      # 首尾状态、帧数和场景参数检查
```

每个脚本都应可重复运行，并只修改以 `LOOP10_` 开头的集合、对象、材质和节点组。

## 8. 验收清单

### 画面

- [ ] 主体一眼可识别，背景层级不混乱。
- [ ] 前景、中景、后景形成明确纵深，不是单个物体放在空背景中。
- [ ] 金属、玻璃、薄膜和发光材质之间有清晰区分。
- [ ] 高光随形体连续流动，没有默认材质感和廉价 Bloom。
- [ ] 四个关键相位都能单独作为高质量静帧展示。
- [ ] 左侧文字安全区在整个 10 秒内保持低细节。
- [ ] 桌面和移动端裁切均成立。
- [ ] 没有随机闪烁、材质跳变或体积噪点突变。
- [ ] 没有纯黑、纯白或高频细节持续抢夺注意力。

### 循环

- [ ] 第 1 帧与第 301 帧场景状态一致。
- [ ] 第 300 帧回到第 1 帧时运动方向和速度连续。
- [ ] 连续播放 5 次无法通过肉眼定位接缝。
- [ ] 没有为了隐藏接缝而加入交叉淡化。

### 文件

- [ ] 1920 × 1080。
- [ ] 30 fps。
- [ ] 300 个成片帧。
- [ ] 10.000 秒，误差不超过 1 帧。
- [ ] H.264 MP4、YUV 4:2:0、无音轨。
- [ ] 文件体积不超过 15 MB。
- [ ] 浏览器内自动播放、静音循环时无白闪。

## 9. 风险与止损条件

| 风险 | 预防方式 | 止损条件 |
| --- | --- | --- |
| Blender MCP 未连接 | 先完成 Gate 0 | 未连接时不编写依赖场景状态的执行脚本 |
| 动画看似循环但速度接缝明显 | 使用线性插值和周期函数 | 第 1/301 帧一致但仍有跳变时，检查切线和运动模糊，不提高渲染质量 |
| 体积雾或噪声无法循环 | 使用静态体积或周期坐标 | 两轮仍闪烁就移除体积动画 |
| 画面堆料但仍显廉价 | 先锁定轮廓、材质分离和主光方向 | 不继续增加粒子或 Bloom，返回 LookDev 静帧阶段 |
| 渲染时间过长 | Eevee、720p 预览、逐 Gate 锁定 | 预览超过 10 分钟或最终估算超过 90 分钟时，先减少体积采样、透明层和阴影成本 |
| 文件过大 | 控制纹理、码率和画面噪声 | 超过 15 MB 时先优化编码和高频细节，不直接降低帧率 |
| 移动端裁切失效 | Gate 1 同时检查竖屏裁切 | 主体无法在中心裁切中成立时返回构图阶段 |

## 10. 本轮不做的内容

- 不复用 `immersive-future` 的模型、图片、动效或代码。
- 不生成角色、鸟、植物或需要骨骼绑定的对象。
- 不制作声音。
- 不先做 4K、透明视频或多主题版本。
- 不把网页文字、Logo 或 UI 烘焙进视频。
- 不在 720p 循环预览通过前渲染最终 1080p 视频。
