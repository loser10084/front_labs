## 当前 v3 多视图

- `venus-restoration-front-v3.png`：正面 0°
- `venus-restoration-front-left-45-v3.png`：前左 45°，黑曜石肩一侧
- `venus-restoration-left-90-v3.png`：左侧 90°，黑曜石肩一侧
- `venus-restoration-back-180-v3.png`：背面 180°
- `venus-restoration-right-90-v3.png`：右侧 90°，大理石肩一侧
- `venus-restoration-front-right-45-v3.png`：前右 45°，大理石肩一侧

主体必须是标准断臂维纳斯造型，而不是泛化的古典女神：保留 S 形扭转、头部偏转、肩胯反向倾斜、重心腿和从髋部开始的经典斜向垂褶。上身使用贴体、高领、无袖的石质内袍遮蔽，但不能改变躯干扭转和整体轮廓。

可见材质目标比例为约 40% 暖象牙色大理石、30% 黑曜石、20% 烟熏透明树脂、10% 深色旧金属。黑曜石和树脂必须形成跨越肩部、躯干、髋部与下部衣褶的大块连续修复区；金属只用于解释连接和受力，不把雕像做成机械装甲。

## 已否决参考

- `venus-restoration-front-v1.png`：姿态过直，服装从肩部形成完整长裙，丢失标准维纳斯结构。
- `venus-restoration-front-v2.png`：造型方向正确，但其他修复材质占比不足，保留为姿态参考。
- `rejected-generic-goddess-front-left-v1.png`：继承了错误母版，仅作为失败记录，禁止用于混元。

六张图保持相同的脸、发型、服装褶皱、断臂截面、材质分区、站姿、比例、光线和灰色背景。混元上传时建议按上述顺序选择全部六张，不混入 v1、v2 或 `rejected-*` 文件。

## 不进入多视图的内容

- 黑色基座、地面裂口与展厅。
- 浮动碎片、尘埃与扫描光。
- 文字、标注、支架、杆件、脚手架和额外道具。

这些内容在混元 GLB 返回后由 Blender 单独制作，避免被烘进主体网格。
