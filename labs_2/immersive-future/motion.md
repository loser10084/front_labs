# 未来世界官网复刻：动效规范

> 本文将真实浏览器观察与未来世界版本的实现建议分开记录。参考站采用固定视口和虚拟滚动，浏览器实测 `body` 为 `overflow: hidden`、文档高度等于视口高度，画面由内部滚动状态驱动。

## 1. 动效原则

动效目标是让用户感觉镜头持续穿过同一个未来世界，而不是在独立页面之间切换。

1. 同方向：向下滚动时镜头和内容持续向前，禁止突然反向、回弹或无原因横跳。
2. 连续：章节之间用共享 3D 对象、背景纹理和媒体平面连接，避免硬切。
3. 清晰：文字必须在稳定区间保持可读，不把模糊当成主要转场。
4. 可逆：向上滚动应沿相同轨迹自然回放。390px 移动端反向滚动已在参考站验证。
5. 克制：默认只同时出现一个主运动和一个次运动。

## 2. 参考站观察

### 2.1 加载与入场

- 首次加载有 0–100 数字进度；加载完成后品牌、标题、菜单和背景浮雕进入。
- 首屏 3D 浮雕在浅灰背景中缓慢漂移，运动幅度很小。
- 页面提供“Click to enable sound”，但声音默认关闭；这是浏览器自动播放限制下的正确做法。

### 2.2 滚动系统

- 浏览器原生滚动条不承担页面位移，滚轮输入被转换为平滑的内部进度。
- 文字章节沿纵向通过视口；3D 浮雕的速度与方向不同，形成轻微视差。
- 桌面项目媒体作为 WebGL/Canvas 纹理平面出现，进入时伴随平移、缩放或轻微透视。
- 项目描述与媒体错时进入：先建立画面，再出现描述与元信息。
- 上滚时同一章节沿原轨迹返回，没有观察到强制吸附或反弹。

### 2.3 媒体与声音

- 网络取证显示项目画面主要使用 KTX2 纹理，部分章节按需请求 MP4 并映射到 WebGL 平面。
- 站点加载动作音、页面切换雷声和石材开裂循环三类 MP3。
- 常驻声音开关显示 `Off / On`，不隐藏当前状态。

| --- | --- | --- | --- | --- |
| 0.00–0.08 | Gateway | 首屏建立 | 字标与标题淡入 | 轨道环从右上缓慢穿过 |

| 0.17–0.26 | Protocol | 构图居中 | 小标题先到、正文后到 | 数据植物由左缘显现 |

## 4. 单章节动效配方

`ProjectChapter` 的局部进度 `p` 分为四段：

```text
0.00 ───── 0.18 ───────── 0.72 ───── 0.90 ───── 1.00
预备          进入             稳定          离场          清理
```

- `0.00–0.18`：背景 3D 对象先进入，媒体仍在视口外或缩放为 0.86。
- `0.18–0.34`：媒体平面进入并稳定，透明度 0 → 1，缩放 0.86 → 1。
- `0.28–0.42`：描述文字逐行显现，Y 24px → 0；不使用大幅字符飞散。
- `0.34–0.72`：可读稳定区，媒体只保留 1%–2% 的慢缩放或视差。
- `0.72–0.90`：文字先离开，媒体随后移出；下一章节的共享对象同时出现。
- `0.90–1.00`：只做状态清理，不在此处引入新的视觉焦点。

建议缓动：

- 滚动驱动属性：`scrub: 0.8–1.2`，保持与输入同步。
- 独立淡入：`power2.out`，0.7–1.0s。
- 媒体展开：`expo.out`，只用于非 scrub 的首次进入。
- 离场：`power2.inOut`。
- 不使用 elastic/bounce。

## 5. GSAP / Three.js 架构

```text
wheel / touch input
        ↓
normalized scroll target
        ↓
GSAP ScrollTrigger + scrub timeline
        ├── DOM text transforms / opacity
        ├── media plane position / scale / shader uniform
        └── Three.js camera + relief group transforms
```

- 页面实现使用 React + Vite；动效层使用 GSAP `ScrollTrigger`。
- 3D 背景使用 Three.js 或 React Three Fiber；不要为每一章节创建独立 WebGL context。
- 单一 `WorldCanvas` 持有所有 3D 场景组，并根据章节进度控制显隐与变换。
- DOM 和 WebGL 共用同一归一化时间线，避免两个滚动系统分别插值造成漂移。
- 媒体可以是 DOM `<video>`，也可以作为 Three.js `VideoTexture`；首轮实现优先选择更容易调试和降级的 DOM 媒体层。

## 6. 关键动效规格

### 6.1 首屏

- 加载器只在真正等待关键资产时出现；缓存命中时不人为延长。
- 品牌与标题：透明度 0 → 1，Y 12px → 0，错开 80ms。
- 轨道环：初始右上，20–30s 慢速自转；随滚动向左下移动约 12vw。
- 滚动提示在首个章节进度达到 0.12 后淡出。

### 6.2 文本

- 大段文字按行 reveal，不按单字符大面积切割，以减轻 DOM 和可访问性负担。
- 文字稳定区禁止模糊；过渡中最大 blur 也不超过 2px，并优先用透明度与位移替代。
- 标题和项目描述不要同时大幅移动；一项稳定后再引入另一项。

### 6.3 媒体

- 默认进入：`translateY(12vh) scale(0.86)` → `translateY(0) scale(1)`。
- 视差速度：媒体 1.0，背景浮雕 0.55，远景粒子 0.25。
- 悬停：媒体缩放最多 1.025，元信息平移 4px；不改变布局尺寸。
- 视频进入前显示同构 poster，播放后不得闪白。

### 6.4 指针

- 桌面可使用 8px 黑点作为自定义指针核心；链接区域扩展为 36–48px 的细线圆环。
- 指针只跟随输入，不添加长拖尾；触屏完全禁用自定义指针。

### 6.5 声音

- 默认 `Off`，首次点击 `On` 后再恢复 `AudioContext`。
- 环境音保持约 -24 LUFS 的低存在感；章节提示音比环境音高 4–6dB。
- 切换时使用 250–400ms gain ramp，避免爆音。
- `prefers-reduced-motion` 不等于静音；声音仍由用户单独控制。

## 7. 移动端与性能降级

- 触摸滚动使用自然滚动或低强度平滑，避免桌面式长惯性造成失控。
- 390px 下项目改为单列，媒体进入只保留 Y 位移和淡入，不做大角度透视。
- 同屏最多一个动态视频纹理；离开视口后暂停并释放解码压力。
- Three.js 渲染 DPR 上限：桌面 1.5，移动 1.25。
- 低性能档：关闭粒子、后处理和实时折射，加载预渲染 WebP。
- `prefers-reduced-motion`：禁用惯性、相机推进、自动旋转和 hover 缩放；保留即时章节切换。

## 8. 验收清单

- 桌面 1440 × 1000：正向滚动完整通过所有章节，无跳帧式硬切。
- 移动 390 × 844：没有横向溢出，固定 UI 不遮挡项目描述。
- 反向滚动：所有章节沿同一路径恢复，不反弹、不改方向。
- 快速滚轮：时间线可追赶目标，不越过章节导致空白屏。
- 声音：默认关闭、首次交互后才能播放、切换无爆音。
- 降级：WebGL 禁用、低性能档和 `prefers-reduced-motion` 均可阅读全部内容。
- 媒体：poster 与首帧无闪烁，离屏视频暂停。
