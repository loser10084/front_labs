# 参考视频运动分析

分析范围为录屏 `10.8s–23.3s` 中显示器内的页面。按 `100ms` 间隔抽帧后，可以看出页面使用的是可逆的滚动驱动镜头推进，而不是三个场景的普通淡入淡出。录屏后半段向上滚动时，同一条轨迹被反向播放。

## 总体节奏

| 录屏时间 | 画面状态 | 运动特征 |
| --- | --- | --- |
| 10.8–11.8s | 建筑外观 | 极慢前推，约从 1.00 放大到 1.06，几乎无模糊 |
| 11.8–12.3s | 接近建筑开口 | 推进速度逐渐增加，主体向左偏移 |
| 12.3–13.0s | 外观进入走廊 | 持续向前推进，两层镜头保持相同方向并在较长区间内交接 |
| 13.0–13.4s | 走廊落稳 | 新镜头从略近、偏右的状态减速到正常构图 |
| 13.4–15.7s | 走廊 | 缓慢前移，保持连续微运动 |
| 15.7–16.5s | 走廊进入木质核心 | 第二次加速推进，横向位移比第一次更明显 |
| 16.5–17.1s | 木质核心落稳 | 新镜头减速，标题随后出现 |
| 19.9–23.0s | 反向滚动 | 木质核心 → 走廊 → 外观，沿相同轨迹倒放 |

## 关键时间点

### 外观 → 走廊

| 相对时间 | 外观层 | 走廊层 | 标题 |
| --- | --- | --- | --- |
| 0ms | scale 1.00，清晰 | 不可见 | 外观标题稳定 |
| 100ms | scale 1.08，轻微左移 | 不可见 | 稳定 |
| 200ms | scale 1.20，开始加速 | 极低透明度 | 外观标题开始左移 |
| 300ms | scale 约 1.13，继续前推 | scale 约 1.08、偏右、开始显现 | 外观标题平滑左移退出 |
| 500ms | scale 约 1.23、透明度接近 0 | scale 接近 1、保持清晰 | 走廊第一行开始出现 |
| 800ms | 不可见 | scale 1.00，落稳 | 第二行约晚 80–100ms 落稳 |

### 走廊 → 木质核心

| 相对时间 | 走廊层 | 木质核心层 | 标题 |
| --- | --- | --- | --- |
| 0ms | scale 约 1.05，清晰 | 不可见 | 走廊标题稳定 |
| 100ms | scale 1.12，向左推进 | 不可见 | 标题开始退出 |
| 200ms | scale 约 1.13、持续向左推进 | scale 约 1.07、偏右 | 走廊标题左移退出 |
| 300ms | scale 约 1.22、接近透明 | opacity 平缓增加 | 两组标题短暂交叠但均非满透明 |
| 500ms | 不可见 | scale 1.00，清晰 | 木质标题开始清晰 |
| 800ms | 不可见 | 继续约 1–2% 的慢速推进 | 标题完全落稳 |

## 曲线与层次

- 镜头平稳段采用很小的持续 scale 和 translate，避免静止画面。
- 交接段先加速、后减速，没有明显回弹；滚动输入使用单调收敛的阻尼跟随，不会越过目标位置。
- 快速推进时 scale、translate 和 opacity 联动，全程保持画面清晰，不使用动态模糊或硬边蒙版。
- 新场景在旧场景穿入开口的过程中已经开始进入，因此视觉关系是空间穿越，而非 A 消失后 B 出现。
- 标题晚于镜头落稳，并按行错开约 80–100ms。场景编号与镜头交接同时滚动。

## 实现映射

`main.js` 使用 Web Animations API 建立一条暂停的 `1000ms` 标准化时间轴，并用平滑后的滚动进度设置每条动画的 `currentTime`。三层图片、每行标题和编号都有独立关键帧。滚动输入通过单调阻尼跟随收敛；推镜峰值约为 `1.78`，并使用 3344×1882 的高分辨率素材保持细节。
